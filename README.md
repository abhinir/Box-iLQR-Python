# Box-iLQR

Box-iLQR is a trajectory-optimization algorithm for nonlinear dynamical systems
with componentwise state and control constraints.

The method combines:

- iterative Linear Quadratic Regulator (iLQR)
- logarithmic barriers for box constraints
- adaptive barrier-parameter continuation
- feasibility-preserving line search
- time-varying feedback policies

## Status

The Python implementation is currently under development.
